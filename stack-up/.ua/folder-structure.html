Step 1: Dashboard 📋

app.offers._index.jsx

Merchant yaha saare offers dekhta hai, toggle se active/pause karta hai, aur "Create Offer" button click karta hai.

app/routes/app.offers._index.jsx
Step 2: Selection 🎴

app.offers.new.jsx

Yeh screen 4 discount types dikhati hai: Volume, BOGO, Frequently Bought Together (Paired), aur Product Add-ons.

app/routes/app.offers.new.jsx
Step 3: Create / Edit ✏️

app.offers.[type].create & edit

Merchant product select karta hai aur rules set karta hai (e.g. Buy 2 Get 10% Off). Customize screen se widget text change karta hai.

app/routes/app.offers.*.create.jsx
Step 4: Sharding 📦

app/utils/*Metafields.server.js

Offer save hote hi sharding utility usko ~270 bytes me shrink karke product ke metafield me likhti hai.

app/utils/*Metafields.server.js
Step 5: Theme Widget 🛍️

extensions/stack-up-theme-extension/

Liquid blocks wahi metafield padh kar product page par widget dikhate hain, aur stack-up.js cart add handle karta hai.

blocks/*.liquid & assets/stack-up.js
Step 6: Checkout WASM ⚡

extensions/*-discount/

Customer checkout par jata hai to Shopify ka native WASM function discount calculate karke minus kar deta hai.

extensions/*-discount/src/cart_lines_discounts_generate_run.js
